SOC

 PROJECT SUMMARY

This project provided comprehensive hands-on exposure to Security Operations Center (SOC) operations, alert management, incident response procedures, threat intelligence validation, evidence preservation, and security monitoring practices. Industry-standard frameworks such as CVSS, MITRE ATT&CK, and the NIST Incident Response Lifecycle were applied throughout the project to simulate real-world cybersecurity operations.

Practical activities included alert classification and prioritization, Wazuh dashboard monitoring, TheHive incident ticket creation, VirusTotal and AlienVault OTX threat intelligence validation, Velociraptor evidence collection, SHA256 integrity verification, and a complete attack simulation using Metasploit against a vulnerable Metasploitable2 environment.

The capstone project demonstrated the full SOC workflow from attack detection and triage to containment, evidence preservation, incident documentation, and recovery. Security monitoring tools successfully detected malicious activity, and response actions were performed to mitigate potential impact.

Overall, this project strengthened foundational skills required for entry-level SOC Analyst and Incident Response roles, including log analysis, incident investigation, threat validation, documentation, escalation procedures, and security operations best practices.

⚠️ Disclaimer

This lab is strictly for educational and training purposes only. All activities are performed in isolated virtual environments.
