SOC Advanced Log Analysis & Incident Response Lab

Overview
This project simulates real-world Security Operations Center (SOC) activities, including log analysis, threat intelligence integration, incident response, alert triage, forensic evidence collection, and attack simulation. The lab was built using industry-standard security tools to develop hands-on Blue Team and SOC Analyst skills.

Tools Used
- Elastic Security
- Wazuh
- AlienVault OTX
- VirusTotal
- TheHive
- CrowdSec
- Velociraptor
- FTK Imager
- Metasploit Framework

Key Activities
- Log Correlation and Analysis
- Anomaly Detection
- Threat Intelligence Integration
- Threat Hunting (MITRE ATT&CK)
- Alert Triage and IOC Validation
- Incident Escalation and SITREP Creation
- Memory and Disk Forensics
- Evidence Preservation and Hash Verification
- Attack Simulation and Incident Response

Capstone Project
Simulated a cyberattack against a vulnerable system using Metasploit, detected the activity with Wazuh, performed alert triage, escalated the incident, collected forensic evidence, contained the threat using CrowdSec, and documented the complete incident response lifecycle.
