# CYART SOC Team

## Overview
This repository is a collection of SOC (Security Operations Center) training activities, incident response simulations, and cybersecurity hands-on exercises. It demonstrates practical skills in security monitoring, alert analysis, incident handling, threat intelligence, and digital forensics.

---

## Key Focus Areas

### Security Monitoring
- Alert analysis and prioritization  
- Log analysis and event monitoring  
- Threat detection and investigation  

### Incident Response
- Incident identification and classification  
- Containment, eradication, and recovery  
- Post-incident reporting and lessons learned  

### Threat Intelligence
- IOC validation and enrichment  
- MITRE ATT&CK mapping  
- Threat analysis and research  

### Digital Forensics
- Evidence collection and preservation  
- Memory and artifact analysis  
- Chain of custody documentation  

### SOC Operations
- Alert triage and escalation  
- Ticketing and workflow management  
- Security reporting and documentation
